Spesifikasi Teknis

Server Requirements

  • OS: Windows/Linux/macOS
  • Python: 3.7 atau lebih baru
  • RAM: Minimal 512MB
  • Storage: 100MB free space
  • Network: WiFi/Ethernet

Hardware ESP32

  • MCU: ESP32 (dual-core)
  • WiFi: 802.11 b/g/n (2.4GHz)
  • GPIO: Pin 18 (Servo), Pin 34 (pH)
  • Voltage: 3.3V logic, 5V servo
  • Sensors: pH sensor analog

Technology Stack

  • Backend: Flask + SocketIO
  • Database: SQLite
  • Frontend: HTML5 + CSS3 + JS
  • Charts: Chart.js
  • Icons: Font Awesome
